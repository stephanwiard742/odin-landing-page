# Own Path

A landing page I built to see what I'm capable of after finishing the HTML and CSS Foundations of The Odin Project. My goal was to turn everything I learned into something real and useful: a small website that spreads some joy with quotes and images.

## Live demo

https://stephanwiard742.github.io/odin-landing-page/

## What I learned

- Building a full page section by section with HTML and CSS
- Using Flexbox to place elements next to or under each other, including containers inside containers
- The difference between `margin`, `padding` and `gap`
- Loading a custom font (Roboto) from Google Fonts
- Linking to other websites and opening them in a new tab
- Committing often with clear commit messages
